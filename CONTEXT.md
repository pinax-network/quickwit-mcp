# Context Glossary

## Index

A named Quickwit collection that can be inspected or searched.

## Index Summary

A compact description of an Index intended for MCP clients and agents.

## Raw Index Metadata

The unmodified metadata returned by Quickwit for an Index.

## Search Target

The single exact Index selected for a search operation.

## Operational Log Search

A bounded search over log records intended for incident investigation or service debugging.

## Index Field

A named field in an Index that represents a useful part of a log record.

## Tool

A readonly MCP operation exposed by this service.
